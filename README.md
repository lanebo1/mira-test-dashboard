# Home Server Dashboard

Modern web dashboard for Linux home server monitoring.

## Features

- **System Metrics**: CPU, RAM, Disk, Network usage in real-time
- **Process List**: View and monitor running processes
- **Interactive Terminal**: Web-based terminal (xterm.js)
- **Modern UI**: Dark theme with beautiful charts
- **Auto-refresh**: Live data updates

## Installation

```bash
# Clone the repository
git clone https://github.com/lanebo1/mira-test-dashboard.git
cd mira-test-dashboard

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
python app.py
```

## Access

Open in browser: `http://your-server:5000`

## Terminal

Click the terminal icon to open interactive shell.

## Security Note

⚠️ This dashboard provides full system access. 
Only use on trusted networks or add authentication.
